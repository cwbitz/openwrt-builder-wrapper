# SSH Permission Configuration

## 概述

此模块用于配置 SSH 授权密钥文件的权限，确保 SSH 公钥认证的安全性和正确性。

## 功能

- 修正 SSH 授权密钥文件权限
- 确保 SSH 公钥认证正常工作
- 提高系统安全性
- 符合 SSH 安全标准（保护私密数据）

## 实现原理

### 权限设置
- 检查 `/etc/dropbear/authorized_keys` 文件是否存在
- 将文件权限设置为 `600`（`rw-------`）
- 确保 SSH 服务可以正确读取授权密钥，且防止其他非管理员用户读取该文件。

### 安全标准
- `600` 权限仅允许所有者读写，禁止任何其他用户读取或修改。
- 符合 SSH 服务（特别是 Dropbear）对授权密钥文件的严格权限安全要求。
- 防止权限过于宽松导致的安全漏洞或 Dropbear 拒绝使用密钥的问题。

## 技术细节

### Dropbear SSH
- OpenWrt 默认使用 Dropbear 作为 SSH 服务器
- 授权密钥文件位置：`/etc/dropbear/authorized_keys`
- 每行一个标准 SSH 公钥格式

### 权限说明
- **`600` (rw-------)**
  - 所有者：读写权限
  - 组用户：无任何权限
  - 其他用户：无任何权限

## 配置文件

- `files/etc/uci-defaults/99-ssh` - SSH 权限配置脚本

## 使用场景

适用于需要 SSH 密钥认证的场景：
- 无密码 SSH 登录
- 自动化部署脚本
- 安全远程管理
- CI/CD 集成

## 注意事项

- 仅在授权密钥文件存在时执行
- 不会创建不存在的文件
- 权限设置在系统首次启动时应用
- 需要配合已存有的 SSH 公钥使用
